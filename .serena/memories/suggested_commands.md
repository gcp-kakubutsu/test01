# よく使うコマンド
- `npm run dev` : TurbopackでNext.js開発サーバーをポート9002で起動。
- `npm run build` : 本番ビルドを生成。
- `npm run start` : `next start` でビルド済みアプリを起動。
- `npm run lint` : Next.jsのESLintルールで静的解析を実行。
- `npm run typecheck` : TypeScriptの型チェックをnoEmitで実施。
- `npm run test` / `npm run test:watch` / `npm run test:coverage` : Jestでテストを実行。
- `npm run genkit:dev` / `npm run genkit:watch` : Genkitの開発ワークフローを起動。
