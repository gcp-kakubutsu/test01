# 005_サブスクリプション状況表示コンポーネント

## 機能概要
ユーザーのサブスクリプション状況を表示し、プラン管理機能を提供するReactコンポーネントを実装する。

## 詳細要件
- プラン状態に応じたバッジ表示
- 残り日数、次回決済日の表示
- 決済失敗、猶予期間中の警告表示
- アップグレード・管理ボタンの表示
- ローディング、エラー状態のハンドリング
