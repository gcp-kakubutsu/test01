# 006_プラン選択画面実装

## 機能概要
ユーザーがサブスクリプションプランを選択・購入できる画面を実装する。料金プランの比較、特典表示、選択機能を含む。

## 詳細要件
- 4種類のプラン（1/3/6/12ヶ月）の表示
- 割引率、人気プランの強調表示
- 月額換算価格と合計価格の表示
- プラン特典のリスト表示
- 選択状態の管理と表示
