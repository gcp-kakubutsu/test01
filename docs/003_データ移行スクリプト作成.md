# 003_データ移行スクリプト作成

## 機能概要
既存ユーザーデータにサブスクリプション関連フィールドを追加し、料金プランデータを作成する移行スクリプトを実装する。

## 詳細要件
- Firebase Admin SDKを使用したデータ移行
- 既存ユーザーデータへのデフォルト値追加
- 料金プランデータの初期セットアップ
- 移行前データの保持
