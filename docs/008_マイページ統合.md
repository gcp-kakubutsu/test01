# 008_マイページ統合

## 機能概要
マイページ（プロフィールページ）にサブスクリプション状況表示を統合し、ユーザーがプラン状態を確認・管理できるようにする。

## 詳細要件
- プロフィールページへのサブスクリプションセクション追加
- サブスクリプション状態コンポーネントの統合
- プラン管理へのナビゲーション
- モバイル対応の最適化
