# 002_ユーザー管理機能更新

## 機能概要
既存のユーザー管理機能を拡張し、payment_uidの自動生成・管理・検索機能を追加する。新規ユーザー作成時の自動付与と既存ユーザーへの追加機能を実装。

## 詳細要件

### 実装機能
1. 新規ユーザー作成時のpayment_uid自動付与
2. 既存ユーザーへのpayment_uid追加機能
3. payment_uidによるユーザー検索機能
4. 全既存ユーザーへの一括付与機能
5. payment_uid関連のタイムスタンプ管理

### データ構造
```javascript
{
  payment_uid: string,           // 16桁の決済用UID
  payment_uid_created_at: Date,  // 生成日時
  payment_uid_updated_at: Date   // 更新日時
}
```
