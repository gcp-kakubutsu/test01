# 004_フック実装

## 機能概要
React Hooksを実装し、payment_uidの管理と決済情報の取得を簡単に行えるようにする。useUserフックの拡張とusePaymentフックの新規作成。

## 詳細要件

### 実装内容
1. useUserフックへのpayment_uid機能追加
2. payment_uid自動生成機能の組み込み
3. usePaymentフックの新規作成
4. 決済情報の取得・管理機能
5. エラーハンドリングとローディング状態管理

### 提供する機能
- payment_uidの取得・確認
- payment_uid情報の詳細取得
- 決済履歴の取得
- 決済統計の計算
