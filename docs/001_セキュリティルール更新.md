# 001_セキュリティルール更新

## 機能概要
Firestoreのセキュリティルールを更新し、サブスクリプション関連の新規コレクションに対するアクセス制御を実装する。

## 詳細要件
- ユーザーデータ（users）の書き込みをAdmin SDK経由のみに制限
- 新規コレクション（subscriptions, plans, payment_events）のアクセス制御
- 既存コレクションのルールは維持
