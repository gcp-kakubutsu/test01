# 005_UIコンポーネント実装

## 機能概要
payment_uidを表示・管理するためのReactコンポーネントを実装。ユーザープロフィール表示と決済履歴表示の2つの主要コンポーネントを作成。

## 詳細要件

### コンポーネント構成
1. **UserProfileコンポーネント**
   - ユーザー基本情報の表示
   - payment_uidの表示とコピー機能
   - プラン情報の表示

2. **PaymentHistoryコンポーネント**
   - 決済履歴の一覧表示
   - 決済統計の表示
   - ステータス別のバッジ表示

### UI/UX要件
- payment_uidのワンクリックコピー機能
- ローディング状態の表示
- エラー状態の適切な表示
- レスポンシブデザイン対応
