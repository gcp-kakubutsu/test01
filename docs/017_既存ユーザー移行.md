# 007_既存ユーザー移行

## 機能概要
本番環境の既存ユーザー全員にpayment_uidを付与する一括移行処理を実装・実行。データの整合性を保ちながら、ダウンタイムなしで移行を完了させる。

## 詳細要件

### 移行戦略
1. **段階的移行アプローチ**
   - バッチ処理による段階的実行
   - 進捗モニタリング
   - ロールバック可能な設計

2. **データ整合性の確保**
   - 重複チェックの徹底
   - トランザクション処理
   - エラーハンドリング

3. **パフォーマンス最適化**
   - バッチサイズの調整
   - 並列処理の検討
   - インデックスの事前作成
